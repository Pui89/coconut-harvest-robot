# Digital Twin and Simulation

Use Isaac Sim/Isaac Lab or Gazebo/ROS 2 as progressively higher-fidelity environments.

Scenario families: daylight/low light, rain/dust/glare, dense canopy, moving leaves/wind, missing RGB/depth, degraded LiDAR, timestamp skew, sensor disagreement, moving humans/animals, unreachable targets, collision-risk targets, actuator faults and emergency stop.

Simulation should emit the same evidence and safety-decision schemas used by recorded-data evaluation so sim-to-real differences can be measured.
