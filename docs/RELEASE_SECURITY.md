# Release and Security Checklist

Before release: run the test matrix, review dependency changes, scan for credentials, verify model/dataset licenses, record model versions and checksums, validate safety-gate behavior, publish provenance/SBOM where configured, and ensure no secrets or raw sensitive sensor data are committed.

Physical deployment additionally requires hardware-specific E-stop validation, workspace limits, collision validation, force/torque limits, operator procedures and applicable agricultural machinery safety review.
